# Banking Transaction Performance Analysis

## Project Overview

This project analyzes 10,000 banking transactions to evaluate transaction performance, customer activity, channel utilization, branch performance, and transaction success rates.

The objective is to transform raw banking transaction data into meaningful business insights that can support operational efficiency, improve service delivery, and strengthen management decision-making.

## Project Objectives

- Analyze overall transaction volume and value.
- Evaluate transaction performance across banking channels.
- Identify branches with the highest transaction activity.
- Examine transaction success, failure, and pending rates.
- Identify trends and patterns in transaction activity.
- Provide actionable recommendations for management.

## Tools and Technologies

- **Microsoft Power BI:** Data modeling, DAX measures, visualization, and dashboard development.
- **Microsoft Excel:** Data review and preparation.

## Dataset Overview

- Total records: 10,000 transactions.
- Unique customers: 2,450.
- Transaction channels: Mobile, Teller, ATM, POS, and Internet.
- Transaction statuses: Successful, Failed, and Pending.

The dataset used for this analysis was derived from another banking transaction dataset.

## Key Performance Indicators (KPIs)

| Metric | Result |
|---|---:|
| Total Transactions | 10,000 |

| Average Transaction Value | ₦296,403 |
| Unique Customers | 2,450 |
| Successful Transactions | 9,389 |
| Transaction Success Rate | 93.89% |
| Failed Transactions | 466 |
| Failure Rate | 4.66% |
| Pending Transactions | 145 |

## Key Business Insights

### 1. Branch Performance
Lagos Island recorded the highest transaction volume, followed by Wuse and Garki. This highlights the concentration of transaction activity across branches.

### 2. Channel Performance
Mobile banking recorded the highest transaction volume and value, demonstrating the importance of digital banking channels. Internet banking recorded the lowest transaction activity.

### 3. Transaction Performance
The dashboard recorded a transaction success rate of 93.89%. However, 466 transactions failed, while 145 remained pending.

## Management Recommendations

- Investigate the causes of failed transactions.
- Improve service capacity at high-volume branches.
- Strengthen the reliability and accessibility of digital banking channels.
- Monitor pending transactions and improve resolution processes.
